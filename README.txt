HEALTH CARE CLINIC — MULTI-PAGE WEBSITE

Files
- index.html: default home page for most web hosts
- Clinic.html: home page retaining the original project filename
- about.html, services.html, reviews.html, visit.html, appointment.html: separate pages
- clinic.css: shared styling
- clinic.js: shared navigation, clinic status and demo appointment form behavior

Preview locally
1. Open this folder in VS Code.
2. If you have the Live Server extension, right-click index.html and choose "Open with Live Server".
3. Otherwise, open index.html in a browser (some features are best tested via a local server).

Important
- Keep all these files in the same folder when uploading/deploying.
- The appointment form is still a front-end demo. It shows a confirmation message locally but does NOT send the request to the clinic or create a confirmed booking. Connect a form backend/service before using it for real appointments.
- Verify the clinic's details, review quotes/ratings, credentials and opening hours with the clinic before publishing.
